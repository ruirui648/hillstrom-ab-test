# Hillstrom 邮件营销 A/B 实验

MineThatData 在 2008 年做过一次邮件营销实验，数据公开后成了营销因果推断的常用样本。6.4 万名客户被随机分成三组：男装邮件、女装邮件、不发邮件，观察两周内的访问、转化和消费。

和用历史数据做「离线分流」不同，这里的组是真的随机分配、邮件也是真的发了，所以组间差异可以解释为邮件的因果效应，而不是相关性。

## 数据

`data/hillstrom.csv`，64,000 行、12 列。

| 字段 | 说明 |
|---|---|
| recency | 距上次购买月数 |
| history / history_segment | 历史消费金额及其分档 |
| mens / womens | 是否买过男装 / 女装 |
| zip_code / channel / newbie | 区域、获客渠道、是否新客 |
| segment | 实验分组：Mens E-Mail / Womens E-Mail / No E-Mail |
| visit / conversion / spend | 两周内是否访问、是否转化、消费金额 |

三组人数：男装 21,307、女装 21,387、对照 21,306。

## 主要结论

| 指标 | 对照组 | 男装邮件 | 女装邮件 |
|---|---|---|---|
| 访问率 | 10.62% | 18.28%（+7.66pp） | 15.14%（+4.52pp） |
| 转化率 | 0.57% | 1.25%（+0.69pp） | 0.88%（+0.31pp） |
| 人均消费 | $0.65 | $1.42（+$0.77） | $1.08（+$0.42） |

- 男装邮件的三项指标都显著（p < 1e-6），女装邮件也显著但更弱，约为男装的六成。
- 按每封邮件 $0.10 估算，男装每千人增量收入约 $770、净收益 $670、ROI 6.7 倍；女装 ROI 3.2 倍。
- 增量集中在高历史消费档：$350 以上的三档人均提升都在 $1.1 以上，$200 以下只有 $0.5 左右。
- 渠道上多渠道路径（Multichannel）最强，电话渠道最弱；老客响应高于新客。
- 以现有样本量，能稳定检出的最小转化率变化是 0.2 个百分点，男装邮件 0.69 个百分点的提升不是噪声。
- 成本敏感性：人均增量收入 $0.77，即单封成本低于 0.77 美元投放就划算，盈亏平衡点远高于常见合同价。

## 方法

- **随机化检验**：连续变量用 Welch t 检验并计算标准化差异，分类变量用卡方，全部 p > 0.05、SMD 接近 0。
- **主效应**：比例指标用两样本比例 z 检验，消费用 Welch t 检验，都给 95% 置信区间。
- **经济性**：用「组间人均消费差 × 人数」算增量收入，再扣邮件成本得到净收益与 ROI。
- **异质性**：按历史消费档、渠道、新老客分组重算增量，样本不足 300 的组不展示。
- **功效**：按实际样本量和基线转化率算最小可检测效应（MDE）。
- **协变量调整（CUPED 思路）**：用实验前的 `history` 做调整，看能否压窄置信区间。
- **uplift 分群**：分别训练邮件组和对照组的转化模型，用预测差排序，看头部能否覆盖更多增量。
- **多重检验**：对异质性分析用 Benjamini-Hochberg 校正，避免分组多导致的假阳性。

## 方法边界验证

这一节记录两次尝试的适用性判断，用来标定方法在这类数据上的边界。

**CUPED 在这里不适用。** `theta` 只有 0.001，方差几乎没降。两周内的消费极度稀疏，大部分人花 0 元，
`history` 解释不了「这周买没买」。协变量调整适合连续型、与前期强相关的指标，对低频事件型结果收益很小。

**两模型 uplift 在当前样本量下不稳定。** 按预测增量分五组后，实际增量与预测不单调相关，Q1 的实际增量甚至最高。
转化率只有 0.6%，正样本几百个，模型学到的是「谁会转化」，不是「谁会被邮件打动」。
在这个数据上，按历史消费档做简单分层，比两模型 uplift 更可靠。

## 已知局限

- 只有一个实验、两周观察窗，长期复购是否被透支无法判断。
- 邮件成本 $0.10 是假设值，已用敏感性分析覆盖 0.02–0.60 区间。
- 异质性分析虽做了 BH 校正，但最顶端 `$1,000+` 档样本仅 880 人，结论不成立。
- uplift 模型受限于转化事件过少，换更大的样本或因果森林（causal forest）才可能稳定。

## 下一轮实验设计

1. 只投高历史消费档 + 多渠道路径，人群规模约为原来的三分之一，预算降下来但保留主要增量。
2. 以 0.2pp 的转化率提升为目标，每组约需 1.5 万人；只投高消费档时人群不够，需要拉长周期或放宽档位。
3. 加一组文案对照：固定发男装邮件，测两个标题，回答「发什么」而不是只回答「发不发」。
4. 观察窗拉长到 8 周，看长期复购是否被这波促销透支。
